# كاشير متعدد الأجهزة

تطبيق كاشير عربي مستقل للكمبيوتر والهاتف. تحفظ المنتجات والمبيعات في قاعدة بيانات Supabase مشتركة، وتُحدّث الأجهزة تلقائياً كل 15 ثانية.

## رابط التطبيق

- التطبيق: <https://eltorkeomar718-blip.github.io/multi-device-cashier/>
- المستودع: <https://github.com/eltorkeomar718-blip/multi-device-cashier>
- يفتح التطبيق مباشرةً دون بريد إلكتروني أو كلمة مرور.
- يستطيع أي شخص لديه الرابط مشاهدة بيانات المتجر وإضافة المنتجات وإتمام المبيعات. لا تستخدمه لبيانات حساسة.

## الإعداد والنشر

- قاعدة البيانات والمخطط وسياسات الأمان أُنشئت في مشروع Supabase مستقل باسم `multi-device-cashier`.
- ملفات SQL المرجعية موجودة في [`schema.sql`](./schema.sql).
- GitHub Actions ينشر التطبيق تلقائياً إلى GitHub Pages عند تحديث فرع `main`.
- `config.js` يحتوي رابط Supabase ومفتاحاً عاماً مخصصاً للمتصفح. لا تضف مفتاح `service_role` أو كلمة مرور قاعدة البيانات إلى المستودع.

المستودع وقاعدة بيانات المتجر متاحان للعامة بناءً على اختيار المالك لتشغيل الكاشير بدون تسجيل دخول. لا يحتوي التطبيق على عزل بين الزوار أو حماية لمعلومات المبيعات.

## ملاحظات

- إتمام البيع يتم في عملية قاعدة بيانات ذرية واحدة مع قفل المخزون، لتجنب البيع فوق الكمية عند استخدام جهازين معاً.
- خطة Supabase المجانية قد توقف المشروع بعد فترة عدم استخدام. أعد تشغيله من لوحة Supabase إذا توقف.
- لا يتضمن الإصدار الحالي الطباعة الحرارية أو المرتجعات أو التقارير المتقدمة.
