# كاشير متعدد الأجهزة

تطبيق كاشير مستقل يعمل في المتصفح ويحفظ المنتجات والمبيعات في قاعدة بيانات Supabase خاصة بهذا المشروع. الواجهة تستجيب للهاتف والكمبيوتر، وتعيد تحميل البيانات كل 15 ثانية.

## إعداد قاعدة البيانات

1. أنشئ مشروع Supabase جديداً على الخطة المجانية، مع تفعيل **Enable automatic RLS** وإيقاف **Automatically expose new tables**.
2. من **SQL Editor** شغّل كامل محتوى [`schema.sql`](./schema.sql).
3. من **Authentication → Users** أضف حساب المالك، وفعّل تأكيد البريد للحساب الذي تنشئه. لا يوجد تسجيل عام داخل التطبيق.
4. انسخ UUID الخاص بالمستخدم من صفحة المستخدمين. في SQL Editor نفّذ الاستعلام التالي بعد استبدال القيم:

   ```sql
   insert into public.stores (name) values ('متجري') returning id;
   ```

   انسخ `id` الناتج، ثم اربط الحساب بالمتجر:

   ```sql
   insert into public.profiles (user_id, store_id, role)
   values ('AUTH_USER_UUID', 'STORE_UUID', 'owner');
   ```

   لا تنشر معرفات الحساب أو كلمة مروره. سيمنع RLS المستخدمين من رؤية بيانات متجر آخر.

## إعداد التطبيق والنشر

1. من إعدادات مشروع Supabase انسخ **Project URL** و **Publishable key** (أو المفتاح العام `anon` القديم).
2. ضع القيم في `config.js`. هذه المفاتيح العامة مخصصة للاستخدام في المتصفح؛ لا تضع `service_role` أو كلمة مرور قاعدة البيانات في هذا المستودع.
3. اضبط مستودع GitHub ليستخدم **GitHub Actions** للنشر من **Settings → Pages → Build and deployment → Source**. سير العمل في `.github/workflows/pages.yml` ينشر الموقع تلقائياً مع كل تحديث لفرع `main`.
4. افتح رابط Pages على كل جهاز وسجّل الدخول بنفس حساب المالك.

المشروع خاص على GitHub، لذلك يمكن نشر ملفات Pages للعامة حتى مع بقاء المستودع خاصاً. لا تضع بيانات عملاء حساسة أو مفاتيح إدارية في الواجهة.

## التشغيل المحلي

بعد ضبط `config.js`، افتح `index.html` عبر خادم ملفات محلي ثابت، أو استخدم GitHub Pages. لا تكفي معاينة الملفات محلياً بعض القيود الأمنية للمتصفح.

## حدود النسخة الحالية

- المبيعات تُسجّل بعملية قاعدة بيانات واحدة وتُخصم الكميات بشكل ذري لمنع البيع فوق المخزون عند استخدام جهازين.
- تحديث الأجهزة الأخرى تلقائي كل 15 ثانية.
- خطة Supabase المجانية قد توقف المشروع بعد فترة عدم استخدام؛ عندها يلزم إيقاظ المشروع من لوحة Supabase. لا توجد رسوم مدفوعة مفعّلة في هذا الإعداد.
- لا يتضمن التطبيق حتى الآن طباعة حرارية أو مرتجعات أو تقارير متقدمة.
