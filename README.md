# كاشير متعدد الأجهزة

تطبيق كاشير عربي مستقل للكمبيوتر والهاتف. يحفظ بيانات المتجر في Supabase ويزامن التغييرات بين الأجهزة.

## رابط التطبيق

- التطبيق: <https://eltorkeomar718-blip.github.io/multi-device-cashier/>
- المستودع: <https://github.com/eltorkeomar718-blip/multi-device-cashier>
- يتطلب اختيار حساب نشط وكلمة مروره؛ لا يعرض التطبيق البريد الإلكتروني.
- الحساب `ist` هو المالك، ويمكنه إنشاء الحسابات الأخرى وتحديد صلاحياتها وتعطيلها وتغيير كلمات مرورها.
- الحسابات الجديدة تبدأ بصلاحيات الرئيسية والبيع والورديات فقط. يستطيع `ist` تعديل الصلاحيات لاحقًا.

## الإعداد والنشر

- قاعدة البيانات أُنشئت في مشروع Supabase مستقل باسم `multi-device-cashier`.
- `schema.sql` هو المخطط الأساسي. شغّل بعده [`migration_accounts.sql`](./migration_accounts.sql) من SQL Editor لتفعيل الحسابات وإلغاء وصول `anon` إلى بيانات المتجر.
- انشر Supabase Edge Function `account-auth` من [`supabase/functions/account-auth/index.ts`](./supabase/functions/account-auth/index.ts) باستخدام Supabase CLI أو محرر Edge Functions في لوحة المشروع. عطّل خيار `Verify JWT` للدالة؛ فهي تتحقق من كلمة المرور في تسجيل الدخول ومن جلسة المالك داخليًا. الدالة تستخدم `SUPABASE_SERVICE_ROLE_KEY` في بيئة الخادم فقط؛ لا تنسخه إلى `config.js` أو GitHub.
- انشر ملفات الواجهة إلى GitHub Pages بعد تجهيز الدالة. في أول تسجيل دخول استخدم `ist` وكلمة مرور حساب المالك الحالي.
- GitHub Actions ينشر التطبيق تلقائياً إلى GitHub Pages عند تحديث فرع `main`.
- `config.js` يحتوي رابط Supabase ومفتاحاً عاماً مخصصاً للمتصفح. لا تضف مفتاح `service_role` أو كلمة مرور قاعدة البيانات إلى المستودع.

ترتيب التفعيل: انشر Edge Function، حدّث GitHub Pages، ثم شغّل ترحيل الحسابات في SQL Editor. يؤدي الترحيل إلى إلغاء الوصول العام؛ قد يتوقف الإصدار القديم عن العمل حتى يصبح الإصدار الجديد متاحًا.

## ملاحظات

- تشمل الوظائف نقطة البيع، الأصناف والمخزون، العملاء والموردين، المشتريات، المديونيات والتحصيلات، الفواتير المعلّقة، الورديات والجرد وتسوية الفروقات، إعدادات البون والطباعة، والنسخ الاحتياطي والاستعادة.
- تحفظ كل عملية تحديث حالة المتجر برقم إصدار؛ إذا عدّل جهازان البيانات في الوقت نفسه يُرفض التحديث الأقدم بدلاً من الكتابة فوق نسخة أحدث.
- دوال قاعدة البيانات تتطلب مستخدمًا مصادقًا عليه وتتحقق من صلاحيات الحساب قبل الحفظ. إنشاء الحسابات وتغييرها يتم من Edge Function، ولا تُحفظ كلمات المرور ضمن بيانات المتجر.
- الأرقام والبيانات في النسخة المستقلة منفصلة عن النظام القديم، ولا تُنقل تلقائياً.
- خطة Supabase المجانية قد توقف المشروع بعد فترة عدم استخدام. أعد تشغيله من لوحة Supabase إذا توقف.
- لا يتضمن الإصدار الحالي المرتجعات.
